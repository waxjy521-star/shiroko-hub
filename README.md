# KIVOTOS HUB · 基沃托斯线上世界 V1

这是一个可直接在浏览器打开的静态网页原型，面向手机和电脑布局。

## 文件
- `index.html`：页面结构
- `style.css`：视觉设计与响应式布局
- `app.js`：页面切换、学生筛选、收藏、学园地图交互、养成目标与便笺本地保存

## 运行
1. 解压 ZIP。
2. 用浏览器打开 `index.html` 即可预览。
3. 想公开访问时，可将三个文件上传到 GitHub 仓库并使用 GitHub Pages 部署。

## 当前原型包含
- 首页与功能入口
- 学生档案示例、搜索、学园/定位筛选
- 收藏学生并在收藏页查看
- 可点击的学园地图示意
- 养成目标清单与完成进度
- 创作空间便笺
- 手机端导航与响应式布局

## 重要说明
- 这是第一版演示数据，不是完整学生数据库。角色卡片使用文字与原创色块占位，不含官方角色图片。
- 收藏、规划与便笺保存在当前浏览器的 localStorage 中，不包含账号系统或云同步。
- 网站为粉丝项目概念原型，与官方无隶属关系。
- 外部字体来自 Google Fonts；若无法联网，网页会回退到系统字体。

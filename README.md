# Shiroko Hub · 蔚蓝档案综合站 V1.0

一个可直接在浏览器运行的静态网站初版，适配手机与桌面。

## 当前功能
- 蓝白科技风首页与响应式布局
- 学生档案卡片、关键词搜索、学园筛选、详情弹窗
- 学生收藏与收藏列表
- 随机学生工具
- 本地备忘录自动保存
- 浅色/深色主题切换
- 使用浏览器 localStorage 保存收藏、主题与备忘录

## 本地运行
解压文件后，打开 `index.html` 即可体验。建议使用现代浏览器。

## 免费发布到 GitHub Pages
1. 登录 GitHub，新建一个公开仓库，例如 `shiroko-hub`。
2. 上传本文件夹内的 `index.html`、`style.css`、`app.js`、`README.md`。
3. 在仓库打开 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
5. 等待部署完成后，GitHub Pages 会提供网站地址。

## 当前限制
- 学生档案是用于体验布局的示例数据，并非完整或实时游戏数据库。
- 目前没有账号注册、跨设备同步、服务器或实时游戏数据接口。
- 收藏和备忘录只保存在当前浏览器；清理浏览器数据可能导致内容丢失。
- 不要把 API 密钥、密码或其他秘密写入公开仓库。

# Shiroko Hub 初版重设计

这是一个纯静态网页，不需要服务器、数据库或付费 API。包含：

- `index.html`：页面结构
- `style.css`：蓝白玻璃拟态风格、暗色主题、手机适配
- `app.js`：搜索、学校筛选、排序、收藏、随机发现、档案弹窗
- `student-data.js`：根据你提交的名称清单整理的初始数据

## 如何上传到 GitHub

1. 先备份仓库里原来的 `index.html`、`style.css`、`app.js`。
2. 在仓库根目录上传这四个文件，替换同名文件，并新增 `student-data.js`。
3. 不要把文件放进子文件夹，四个网页文件应在同一层目录。
4. 提交（Commit）更改。
5. 如果仓库启用了 GitHub Pages，等待部署完成后刷新网站；首次部署需要在仓库 Settings → Pages 里选择正确的发布分支和目录。

## 本地预览

下载并解压后，直接用浏览器打开 `index.html` 即可预览主要功能。若某些浏览器限制本地文件脚本，可通过 GitHub Pages 预览。

## 资料准确性说明

这是一份界面和功能初版，不是已经核验完毕的官方百科。学生名称源于用户提供的名单，名单的完整性、个别译名、学校归属和形态名称仍需要校对。技能、攻击类型、防御类型、角色定位、升级材料暂标记为“待核实”，没有编造官方数值。请在核对可靠来源后再补齐这些资料。

## 隐私

收藏和主题偏好保存在当前浏览器的 `localStorage`。没有账号系统，也不会把收藏同步到其他设备。
